# A2A3 (Ascend 910B/910C) 硬件索引

> **精确数字以 `AscendC_platform/Ascend910B*.ini` 为准**。本文件只给代表性配置与设计影响归纳，不维护第二份真值表。

## 对应 ini

- `Ascend910B.ini` / `Ascend910B1.ini` / `Ascend910B2.ini` / `Ascend910B2C.ini` / `Ascend910B3.ini` / `Ascend910B4*.ini`
- A3：`Ascend910_93*.ini`
- 看 `[AICoreSpec]` 的 `cube_core_cnt` / `vector_core_cnt` / `l0_[abc]_size` / `ub_size` / `fb0_size`

## 代表性配置（精确值看 ini，勿写死）

- AI Core / Cube：~24（910B 代表值，按 variant 看 ini）
- L0C：128KB；UB：192KB；Bias：1KB；L0A/L0B：64KB
- HBM：64GB；L2：192MB
- AIC 版本：dav-c220-cube；AIV：dav-c220-vec

> 不同 variant（B1/B2/B3/B4/910_93）数字可能不同，**以对应 ini 为准**。

## 设计要点（A2A3 特性）

- **Fixpipe 可用**：支持硬件 Fixpipe（L0C→OUT/L1），可直接用
- **Sparsity 可用**：支持结构化稀疏硬件加速
- **同地址冲突**：硬件不支持同地址请求并行，分核需错位规避（见 kernel-optimization common）
- **L0C 较小（128KB）**：tile 粒度受限，K 方向需更多轮次
- **Cube:Vector = 1:2**：1 Cube + 2 Vector per AI Core
- **无 L1**（A2A3 无独立 L1 buffer）
