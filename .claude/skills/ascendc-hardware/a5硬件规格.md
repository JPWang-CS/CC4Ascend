# A5 (Ascend 950) 硬件索引

> **精确数字以 `AscendC_platform/Ascend950*.ini` 为准**。950 有多 variant（950DT / 950PR / 各 die），核数因 variant 而异，**勿写死单一数字**。

## 对应 ini

- `Ascend950DT_*.ini`（950DT 系列，多 die）
- `Ascend950PR_*.ini`（950PR 系列）
- 看 `[AICoreSpec]` 的 `ai_core_cnt` / `cube_core_cnt` / `vector_core_cnt` / `l0_[abc]_size` / `l1_size` / `ub_size` / `fb0_size`

## 代表性配置（精确值看 ini，勿写死）

- AI Core / Cube：28~36（950DT_9575 实测 28；官方 docs 代表值 32；**以目标 variant ini 为准**）
- Vector：56~72（同上，按 variant）
- L0C：256KB；UB：~248KB（253952B）；L1：512KB；Bias：4KB
- HBM：128GB；L2：128MB
- AIC 版本：dav-c310-cube；有 fixpipe intrinsic（`fb0_size=4096`）

> ⚠️ 核数最易漂移：旧记忆写 36、docs 写 32、ini(9575) 写 28。**一律以目标 SoC 的 ini 为准**。

## 设计要点（A5 特性）

- **L0C 翻倍（128→256KB）**：tile 粒度可放大，减 K 方向轮次
- **UB 扩大（192→~248KB）**：双/三缓冲阈值上调
- **有 L1（512KB）**：A2A3 无，A5 新增，可做更多片上复用
- **同地址并行**：硬件支持同地址请求并行，分核可简化（无需 A2A3 的错位规避）
- **CrossCore 同步**：`CrossCoreSetFlag/WaitFlag` 需严格匹配（见 development §核间同步）
- **Regbase/SIMT/CV 融合/CCU**：A5 四大新范式（见 development）
- **Fixpipe**：A5 有 fixpipe intrinsic + fb0 buffer，但通路与 A2A3 不同（见 ini `fb0_size` 与 intrinsic 表）
