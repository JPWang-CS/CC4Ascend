# 1 算子需求

## 1.1 设计约束

- 运行环境：A5（Ascend 950），Blaze TensorAPI 路径
- 调用方式：单算子 `aclnnQuantMatmulWeightNz`
- 适用算子：`quantBatchMatmulV3`，MX 全量化路径
- 设计原则：简洁、最小改动、向后兼容

## 1.2 需求描述

### 1.2.1 功能描述

MX 全量化场景，scaleX1/scaleX2 增加 batch 维度支持：

| | 变更前 | 变更后 |
|---|--------|--------|
| scaleX1 shape | `(m, ceil(K/64), 2)` | `(batchA, m, ceil(K/64), 2)` |
| scaleX2 shape | `(k, ceil(N/64), 2)` | `(batchB, k, ceil(N/64), 2)` |

batch 维度数与 x1/x2 的 batch 维度数一致，各维值逐维匹配。

### 1.2.2 适用范围

| 量化类型 | x1 dtype | x2 dtype | scale dtype | x1/x2 维度 | 涉及？ |
|---------|----------|----------|-------------|-----------|--------|
| mx 全量化 | F8_E4M3FN / F8_E5M2 | F8_E4M3FN / F8_E5M2 | F8_E8M0 | 2-6D | ✅ |
| mx 全量化 | F4_E2M1 | F4_E2M1 | F8_E8M0 | 2-6D | ✅ |
| mx A8W4 | F8_E4M3FN | F4_E2M1 (NZ) | F8_E8M0 | x1=2D | ❌ 无batch |
| mx A8W4 | F8_E4M3FN | FLOAT32 (ND) | F8_E8M0 | x1=2D | ❌ 无batch |

x1/x2 为 2D（无 batch）时不涉及；x1/x2 ≥ 3D（有 batch）时 scale 需对应 batch 前缀。

### 1.2.3 精度要求

精度继承原算子 MX 量化标准，满足 mxfp8/mxfp4 精度验收标准。

# 2 算子设计

## 2.1 总体设计

### 2.1.1 核心思想

Scale 维度模型从固定 3 维改为 `batchPrefix + MX3D`：

```
Scale Shape:  [batch_0, ..., batch_N] + [M/ceil(k/64), ceil(k/64)/N, 2]
               ← batchDimNum →           ← MX 固定 3 维 →
               batchDimNum = totalDimNum - 3
```

所有访问 M/K/N/Last 维度的索引统一为 `batchDimNum + offset`。batch 不存在时 `batchDimNum = 0`，退化为原逻辑。

### 2.1.2 与 GMM 的 batch 差异

| | GMM (grouped_matmul_finalize_routing) | QBMM V3 |
|---|------|------|
| batch 本质 | experts 分组，每组 M/N/K 不同 | MatMul 批量，所有 batch 共享 M/N/K |
| x 维度 | 始终 2D `(M, K)` | 2-6D `(batch, M, K)` |
| scale batch 来源 | groupList（experts 个数） | x1/x2 的 batch 维 |
| tiling | 按组独立计算 | 统一，batch 仅作计算量乘数 |
| 需新增 tiling 字段？ | 不需要（复用 groupList） | **不需要**（复用 batchA1-4 / batchB1-4） |

QBMM V3 的 scale batch 信息在 `QuantBatchMatmulV3BasicAPIDataParams` 中已存在（`batchA1-4` / `batchB1-4`），kernel 层直接用现有 batch 维计算 scale stride，不需要新增 tiling 字段。

### 2.1.3 调用链与改动分布

```
aclnn 入口 (aclnn_quant_matmul_v4.cpp)
  └─ CheckDimRange()            ← 第1关：!=3 → <3
       │
Checker (quant_matmul_checker.cpp)
  ├─ CheckMxScaleDimRange()     ← 第2关：!=3 → <3 + batch 逐维匹配
  ├─ CheckDimValueMicroScaling() ← 第3关：硬编码索引 → batchDimNum+offset
  ├─ InferGroupSizeM()          ← 同上
  ├─ InferGroupSizeK()          ← 同上
  └─ InferGroupSizeN()          ← 同上
       │
Tiling Checker (quant_batch_matmul_v3_checker.cpp)
  ├─ MxPertokenScaleShapeCheck() ← 第4关：!=3 → <3 + batch-aware 索引
  ├─ MxScaleShapeCheck()        ← 同上
  └─ CheckBatchValidInMxPerGroupMode() ← 第5关：新增 batch 逐维校验
       │
Kernel (kernel_qbmm_mx.h)
  └─ AddBatchOffset()           ← 第6关：新增 X1SCALE/X2SCALE batch stride
```

### 2.1.4 修改文件

| # | 文件 | 改动 |
|---|------|------|
| 1 | `op_api/aclnn_quant_matmul_v4.cpp` | `CheckDimRange`: gate 放行 |
| 2 | `op_api/quant_matmul_checker.cpp` | 5 个函数：`!=`→`<` + batch 逐维校验 + 索引批量化 |
| 3 | `op_host/.../quant_batch_matmul_v3_checker.cpp` | 2 个函数 + 新增 `CheckBatchValidInMxPerGroupMode` |
| 4 | `op_host/.../quant_batch_matmul_v3_checker.h` | 新增函数声明 |
| 5 | `matmul/common/cmct/kernel/kernel_qbmm_mx.h` | `AddBatchOffset` 新增 X1SCALE/X2SCALE stride |

## 2.2 aclnn 入口层

### 2.2.1 文件

`op_api/aclnn_quant_matmul_v4.cpp`

### 2.2.2 当前代码

**`CheckDimRange()` (L505-520)：** 参数第一道 gate，只做维度数粗略校验。

```cpp
// L132-135: MX 判定
static inline bool isMx(const aclTensor* scale)
{
    return scale->GetDataType() == op::DataType::DT_FLOAT8_E8M0;
}

// L516-517: gate 检查
size_t expectScaleDim = isMx(scale) ? MX_SCALE_DIM_NUM : 1;  // MX_SCALE_DIM_NUM=3
OP_CHECK_WRONG_DIMENSION(scale, expectScaleDim, return false); // 宏内 != 比较
```

`OP_CHECK_WRONG_DIMENSION` 定义（`common/stub/op_api/.../op_error_check.h` L204）：
```cpp
#define OP_CHECK_WRONG_DIMENSION(tensor, expectedDimNum, retExpr) \
  if (tensor->GetViewShape().GetDimNum() != expectedDimNum) {     \  // != 严格相等
    ...
  }
```

**问题：** `!=` 比较，scale dim≥4 时直接拦截。后续 checker 的 batch 感知校验跑不到。

### 2.2.3 设计

将 MX 场景的严格相等 `!=` 替换为最小维度检查 `<`：

```cpp
// 改动后
if (isMx(scale)) {
    OP_CHECK_MIN_DIM(scale, MX_SCALE_DIM_NUM, return false);  // < 比较 → 允许 ≥3D
} else {
    OP_CHECK_WRONG_DIMENSION(scale, 1, return false);          // 非MX保持 !=1
}
```

`OP_CHECK_MIN_DIM` 定义（同文件 L218）：
```cpp
#define OP_CHECK_MIN_DIM(tensor, minDim, retExpr) \
  if (tensor->GetViewShape().GetDimNum() < static_cast<size_t>(minDim)) { ...
```

**`MxScaleContiguousProcess()` (L1599-1636)：** 无需改动。已使用 `dimNum-3/dimNum-2/dimNum-1` 相对索引，天然兼容 batch 前缀。

### 2.2.4 向后兼容

| 场景 | dim | 旧 `!=3` | 新 `<3` |
|------|-----|---------|---------|
| MX 无batch | 3 | 通过 | 通过 |
| MX 1层batch | 4 | **拒绝** | 通过 |
| MX 2层batch | 5 | **拒绝** | 通过 |
| MX 4层batch | 7 | **拒绝** | 通过 |
| MX 非法 | <3 | 拒绝 | 拒绝 |
| 非MX | 1 | 通过 | 通过（走 else 分支） |

## 2.3 Checker 层

### 2.3.1 文件

`op_api/quant_matmul_checker.cpp`

### 2.3.2 CheckMxScaleDimRange（维度数校验）

**当前代码 (L977-996)：**
```cpp
bool QuantMatmulChecker::CheckMxScaleDimRange(size_t x1ScaleDim, size_t x2ScaleDim) const
{
    if (x1ScaleDim != MX_SCALE_DIM) {   // != 严格相等 → 拒绝 >3D
        ...error...
    }
    if (x2ScaleDim != MX_SCALE_DIM) {   // != 严格相等 → 拒绝 >3D
        ...error...
    }
    return true;
}
```

**设计：** `!=` → `<`，并新增 batch 维数与值的逐维匹配。

```cpp
// 改动后
if (x1ScaleDim < MX_SCALE_DIM) { ... }   // < 3 → 拒绝非法
if (x2ScaleDim < MX_SCALE_DIM) { ... }

// 新增：batch 维数匹配
size_t x1BatchDimNum = x1ScaleDim - MX_SCALE_DIM;
size_t x2BatchDimNum = x2ScaleDim - MX_SCALE_DIM;
size_t x1InputBatchDimNum = x1DimNum > 2 ? x1DimNum - 2 : 0;
size_t x2InputBatchDimNum = x2DimNum > 2 ? x2DimNum - 2 : 0;

OP_CHECK(x1BatchDimNum == x1InputBatchDimNum, ...);
OP_CHECK(x2BatchDimNum == x2InputBatchDimNum, ...);

// 新增：逐 batch 维值匹配
for (i = 0; i < x1BatchDimNum; i++)
    OP_CHECK(x1Scale.GetDim(i) == x1.GetDim(i), ...);
for (i = 0; i < x2BatchDimNum; i++)
    OP_CHECK(x2Scale.GetDim(i) == x2.GetDim(i), ...);
```

### 2.3.3 CheckDimValueMicroScaling（M/K/N/Last 值校验）

**当前代码 (L475-511)：** 维度索引硬编码，无 batch 感知。

```cpp
// L477-480: 硬编码索引
auto x1ScaleMDimIndex = transposeX1_ ? 1 : 0;
auto x1ScaleKDimIndex = transposeX1_ ? 0 : 1;
auto x2ScaleNDimIndex = transposeX2_ ? 0 : 1;
auto x2ScaleKDimIndex = transposeX2_ ? 1 : 0;

// L510-511: 硬编码最后一维位置
x1Scale_->GetViewShape().GetDim(MX_SCALE_DIM - 1)   // MX_SCALE_DIM-1 = 2
x2Scale_->GetViewShape().GetDim(MX_SCALE_DIM - 1)
```

**设计：** 索引改为 `batchDimNum + offset`，最后一维改为 `dimNum - 1`。

```cpp
// 改动后
auto x1ScaleDimNum = x1Scale_->GetViewShape().GetDimNum();
auto x2ScaleDimNum = x2Scale_->GetViewShape().GetDimNum();
size_t x1BatchDimNum = x1ScaleDimNum - MX_SCALE_DIM;
size_t x2BatchDimNum = x2ScaleDimNum - MX_SCALE_DIM;

auto x1ScaleMDimIndex = x1BatchDimNum + (transposeX1_ ? 1 : 0);
auto x1ScaleKDimIndex = x1BatchDimNum + (transposeX1_ ? 0 : 1);
auto x2ScaleNDimIndex = x2BatchDimNum + (transposeX2_ ? 0 : 1);
auto x2ScaleKDimIndex = x2BatchDimNum + (transposeX2_ ? 1 : 0);

// 最后一维: 从固定位置改为动态计算
x1Scale_->GetViewShape().GetDim(x1ScaleDimNum - 1)
x2Scale_->GetViewShape().GetDim(x2ScaleDimNum - 1)
```

batch 不存在时 `batchDimNum = 0`，退化为原逻辑。

### 2.3.4 InferGroupSizeM / InferGroupSizeK / InferGroupSizeN

**当前代码：** 硬编码 scale 维度索引，同上面的模式。

```cpp
// InferGroupSizeM L620:
scaleSizeM = x1Scale->GetViewShape().GetDim(transX1 ? 1 : 0);

// InferGroupSizeK L638:
scaleSizeK = x1Scale->GetViewShape().GetDim(transX1 ? 0 : 1) * 64;

// InferGroupSizeN L656:
scaleSizeN = x2Scale->GetViewShape().GetDim(transX2 ? 0 : 1);
```

**设计：** 统一加 `batchDimNum` 偏移。

```cpp
// InferGroupSizeM:
size_t batchDimNum = x1ScaleDimNum - MX_SCALE_DIM;
scaleSizeM = x1Scale->GetViewShape().GetDim(batchDimNum + (transX1 ? 1 : 0));

// InferGroupSizeK:
size_t batchDimNum = x1ScaleDimNum - MX_SCALE_DIM;
scaleSizeK = x1Scale->GetViewShape().GetDim(batchDimNum + (transX1 ? 0 : 1)) * 64;

// InferGroupSizeN:
size_t batchDimNum = x2ScaleDimNum - MX_SCALE_DIM;
scaleSizeN = x2Scale->GetViewShape().GetDim(batchDimNum + (transX2 ? 0 : 1));
```

### 2.4.4 新增 CheckBatchValidInMxPerGroupMode

MX 模式新增 batch 逐维匹配函数，对照 Perblock 路径已有的 `CheckBatchValidInPerblockMode` 模式：

```cpp
bool QuantBatchMatmulV3Checker::CheckBatchValidInMxPerGroupMode(
    const gert::Shape& scaleShape, const gert::Shape& pertoken,
    const gert::Shape& x1Shape, const gert::Shape& x2Shape) const
{
    size_t scaleBatchDimNum = scaleShape.GetDimNum() - SCALE_THREE_DIM;
    size_t pertokenBatchDimNum = pertoken.GetDimNum() - SCALE_THREE_DIM;
    size_t x1BatchDimNum = x1Shape.GetDimNum() > 2 ? x1Shape.GetDimNum() - 2 : 0;
    size_t x2BatchDimNum = x2Shape.GetDimNum() > 2 ? x2Shape.GetDimNum() - 2 : 0;

    // batch 维数匹配
    OP_TILING_CHECK(scaleBatchDimNum == x2BatchDimNum, ...);
    OP_TILING_CHECK(pertokenBatchDimNum == x1BatchDimNum, ...);

    // 逐维值匹配
    for (size_t i = 0; i < scaleBatchDimNum; i++)
        OP_TILING_CHECK(scaleShape.GetDim(i) == x2Shape.GetDim(i), ...);
    for (size_t i = 0; i < pertokenBatchDimNum; i++)
        OP_TILING_CHECK(pertoken.GetDim(i) == x1Shape.GetDim(i), ...);

    return true;
}
```

### 2.4.5 CheckInputValidInMxPerGroupMode 签名变更

```cpp
// 改动前：只传 weightShape
bool CheckInputValidInMxPerGroupMode(

// 改动后：同时传 x1Shape, x2Shape
bool CheckInputValidInMxPerGroupMode(
```

## 2.5 Kernel 层

### 2.5.1 Cmct 内核

**文件：** `matmul/common/cmct/kernel/kernel_qbmm_mx.h`

**当前代码 `AddBatchOffset()` (L282-305)：** 只处理 A/B/C/Bias 的 batch 偏移，**无 scale 的 batch 偏移**。

**设计：** 在 `AddBatchOffset` 中新增 X1SCALE 和 X2SCALE 的 batch stride：

```cpp
// 在 A 偏移之后插入：
Get<QuantBatchMatmul::IDX_X1SCALE_OFFSET>(blockOffset_) +=
    batchAOffset_ * (params.problemShape.m *
        CeilDiv(params.problemShape.k, MXFP_DIVISOR_SIZE) * MXFP_MULTI_BASE_SIZE);

// 在 B 偏移之后、C 偏移之前插入：
Get<QuantBatchMatmul::IDX_X2SCALE_OFFSET>(blockOffset_) +=
    batchBOffset_ * (params.problemShape.n *
        CeilDiv(params.problemShape.k, MXFP_DIVISOR_SIZE) * MXFP_MULTI_BASE_SIZE);
```

- `MXFP_DIVISOR_SIZE = 64`，`MXFP_MULTI_BASE_SIZE = 2`
- `batchAOffset_` / `batchBOffset_`：Cmct 框架 batch 迭代计数器
- X1SCALE (pertokenScale) 偏移跟随 batchA，X2SCALE (scale) 偏移跟随 batchB

### 2.5.2 Blaze 内核

Blaze 路径 `GemmUniversal` 为外部预编译库。当前 wrapper `qbmm_mx_tensor_api_blaze.h` 将 scale 作为单一 `GM_ADDR` 传入。需确认 Blaze 库版本是否已包含等效 batch stride 逻辑；若不支持，需在 wrapper 层或 Blaze 侧补充。

### 2.5.3 Kernel Wrapper

**文件：** `qbmm_mx_tensor_api_blaze.h` / `qbmm_mx_basic_api_cmct.h`

两个 wrapper 传参结构 `{aGM, bGM, cGM, bias, perTokenScale, scale}` 不变，无需改动。
