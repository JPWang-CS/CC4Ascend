# quantBatchMatmulV3 MX Scale Batch 支持 — 需求分析

## 一、需求

MX 量化的 scaleX1/scaleX2 增加 batch 维度支持。

| | 变更前 | 变更后 |
|---|--------|--------|
| scaleX1 shape | `(m, ceil(K/64), 2)` | `(batchA, m, ceil(K/64), 2)` |
| scaleX2 shape | `(k, ceil(N/64), 2)` | `(batchB, k, ceil(N/64), 2)` |
| scale dim 限制 | 恰好 = 3 | ≥ 3（无batch时3，有batch时3+N） |

**修改要求（来自需求.md）：**
> block以及schedule中均感知batch轴，仅kernel的batch间scale偏移需要感知batch的偏移
> tiling：校验相关的修改，切分保持一致
> aclnn：校验相关修改

## 二、参考 PR (gitcode#4112) 完整变更分析

PR 分支 `pr_4112`，3 个 commit：

### Commit 1: `9c488b85d` — add mx_fp4 & mxfp8 scale_batch

**2.1 内核层 — `matmul/common/cmct/kernel/kernel_qbmm_mx.h`** (+4 行)

`AddBatchOffset()` 函数中新增 X1SCALE 和 X2SCALE 的 batch 偏移：
```cpp
// X1SCALE (pertokenScale) batch offset:
Get<IDX_X1SCALE_OFFSET>(blockOffset_) += batchAOffset_ * (m *
    CeilDiv(k, MXFP_DIVISOR_SIZE) * MXFP_MULTI_BASE_SIZE);

// X2SCALE (scale) batch offset:
Get<IDX_X2SCALE_OFFSET>(blockOffset_) += batchBOffset_ * (n *
    CeilDiv(k, MXFP_DIVISOR_SIZE) * MXFP_MULTI_BASE_SIZE);
```
- batch stride = `对应矩阵维度 × ceil(K/64) × 2`
- `batchAOffset_` / `batchBOffset_` 来自 Cmct 框架的 batch 迭代

**⚠️ 注意：** PR 只改了 Cmct 路径，Blaze 路径 (`Blaze::Gemm::Kernel::GemmUniversal`) 未动。

**2.2 Tiling Checker — `quant_batch_matmul_v3_checker.cpp`** (+69 行)

核心改动：

**(a) `MxPertokenScaleShapeCheck`:**

```cpp
// 旧: pertokenShapeLen != 3 → 报错
```

```cpp
// 校验 batch 值:   scaleShape.GetDim(i) == x2Shape.GetDim(i), pertoken.GetDim(i) == x1Shape.GetDim(i)
```

**(d) `CheckInputValidInMxPerGroupMode` 签名变化:**

## 五、设计模式总结

PR 采用的核心模式：

```
┌──────────────────────────────────────────────────────────┐
│  Scale Shape: [batchDims...] + [M, ceil(K/64), 2]        │
│                      ↑                                   │
│              batchDimNum = totalDimNum - 3                │
│                                                          │
│  M/K/N 索引 = batchDimNum + (trans ? 1 : 0 / 0 : 1)     │
│  最后维 = totalDimNum - 1  (始终=2)                       │
│                                                          │
│  Batch stride = M × ceil(K/64) × 2  (per-batch bytes)    │
└──────────────────────────────────────────────────────────┘
```

**batch stride 公式：**
- scaleX1 (pertokenScale): `batchStride = m × CeilDiv(k, 64) × 2`
- scaleX2 (scale):        `batchStride = n × CeilDiv(k, 64) × 2`
- 由 kernel 内部的 `AddBatchOffset` 应用（Cmct）或 Blaze 框架等效逻辑
