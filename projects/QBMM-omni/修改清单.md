## 3. 量化模式分支与落核（完整）

### 3.1 aclnn 入口分支

| 入口 | x2 格式 | 触发条件 | 分派文件 | 分派谓词 |
|------|---------|----------|----------|----------|
| `aclnnAiInfraQuantMatmulV5` | ND | x2=ND | `v4/op_api/aclnn_ai_infra_quant_matmul_v5.cpp:1158`（1062=函数起点）| `isA8W4\|\|IsA8W8Perblock\|\|IsA4W4PergroupNonSym` |
| `aclnnAiInfraQuantMatmulWeightNz` | NZ | x2=NZ | `v3/op_api/aclnn_ai_infra_quant_matmul_v4.cpp:1838`（入口 2110，1756=内部起点）| `isA8W4F\|\|isA8W4I` |

### 3.2 落核判定表

| 量化模式 | x1/x2 | x1Scale/pertoken_scale | x2Scale | offset | bias | 命中谓词 | 落核 |
|----------|-------|------------------------|---------|--------|------|----------|------|
| W8A8 pertensor (T-C) | INT8/INT8 | null | UINT64/INT64 | null | null/INT32 | 无 | **v3** |
| W8A8 perchannel (T-T) | INT8/INT8 | null | UINT64/FLOAT/BF16 | null | null/INT32 | 无 | **v3** |
| W8A8 pertoken (K-C/K-T) | INT8/INT8 | FLOAT[M] | FLOAT/BF16[N] | null | null | 无 | **v3** |
| INT4×INT4 对称 | INT4/INT4 | null | UINT64 | null | null | 无 | **v3** |
| **W8A8 perblock** | INT8/INT8 | FLOAT(≥2D) | FLOAT(≥2D) | null | FLOAT32 | Perblock=T | **v4** |
| **INT4×INT4 pergroup 非对称** | INT4/INT4 | FLOAT[M,1] | FLOAT[⌈k/g⌉,N] | FLOAT16 | null | A4W4NonSym=T | **v4** |
| **A8W4-int** | INT8/INT32 | FLOAT | FLOAT/UINT64 | FLOAT(yOffset) | null | isA8W4Int=T | **v4** |

### 3.3 三谓词精确定义

1. **`isA8W4`**
   - `isA8W4Float`: x1=FLOAT8_E4M3FN, x2=FLOAT4_E2M1 → **950-only**（A2A3 跳过）
   - `isA8W4Int`: x1=INT8, x2=INT32 → **A2A3 支持**

2. **`IsA8W8Perblock`**
   - x1Scale≠null && x1=x2=INT8
   - x1Scale/x2Scale **均 DT_FLOAT**
   - 两 scale 维数分别==x1/x2 维数

3. **`IsA4W4PergroupNonSymmetric`**
   - x1Scale/x2Scale/x2Offset 均非 null
   - x1Scale/x2Scale=FLOAT 且 dim>1
   - **x2Offset=FLOAT16 且 dim>1**
   - bias=null
   - INT4×INT4
   - k%1024==0 && n%256==0

**问题**: `op-plugin` 的 `is_x_scale_same_transpose` 强制 x1↔pertoken_scale、x2↔scale 转置态一致

**迁移注意**:
- 保留 checker 逻辑

**位置**: `op-plugin/ops/opapi/QuantMatmulKernelNpuOpApi.cpp:58-75`

### 7.3 group 推断 3 层（[[qbmm-mx-groupsize-inference-fix]]）

**约束**:
- op-plugin `check_and_get_groups`（只打包，不推断）
- aclnn `InferGroupSize`（checker.cpp:697）
- host `AnalyzeGroupInfo`（tiling_base.cpp:714）

**迁移注意**:
- 三层各留勿重写
- op-plugin 侧不迁移（在 op-plugin 仓）

### 7.4 IsMicroScaling 合轴守卫（[[qbmm-mx-batchA-mfusion-guard]]）

**问题**: scale-batch 提交时误删 `CheckFusionBatchA` 的 `IsMicroScaling` 禁合轴守卫

**影响**: A_batch-B_no_batch 合 M 走 `WITHOUT_BATCH` kernel，TilingKey 8196 应变 10500

**迁移注意**:
- 检查所有 fusion 相关代码
- 但 MX 已 DEFER，此条对 A2A3 迁移影响小

### 7.5 MX scale 语义（[[mx-quant-scale-semantics]]）

**问题**: MX FP4 量化 scale shape 布局复杂，涉及 batch 维前缀、groupK=32、cube 内 per-group apply

**约束**:
- scale shape: `(M, ceil(K/64), 2)` + batch 前缀

**迁移注意**: MX 已 DEFER，不适用
