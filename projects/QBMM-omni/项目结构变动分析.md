## 1. 结构差异汇总

### 1.1 顶层目录结构变化

| 变化类型 | ops-nn | omni-ops | 说明 |
|----------|--------|----------|------|
| **位置变化** | ops-nn/matmul/ | omni-ops/inference/ascendc/src/ops-nn/matmul/ | 嵌套路径加深 |
| **算子组织** | 20+ 个独立算子目录 | common/ + ai_infra_matmul/ | 独立算子 → 算子+共享common |
| **CMake 发现** | 各算子独立 CMakeLists | func.cmake op_add_subdirectory glob | 自动发现机制 |

### 1.2 关键变化点

| # | 变化点 | ops-nn | omni-ops |
|---|--------|--------|----------|
| 1 | common 代码位置 | matmul/common/（分散在各算子内） | matmul/common/（集中共享） |
| 2 | cmct kernel 模板 | matmul/common/cmct/（大量 .h） | 不迁（A5 only） |
| 3 | op_api 位置 | 各算子 op_api/ | 集中到 common/op_host/op_api/ |
| 4 | op_tiling 位置 | 各算子 op_host/op_tiling/ | 部分集中到 common/op_host/op_tiling/ |
| 5 | config 位置 | 各算子 op_host/config/ | 各算子 op_host/config/ |

## 5. CMakeLists 变化详解

### 5.1 ops-nn → omni-ops 关键差异

| 项目 | ops-nn | omni-ops |
|------|--------|----------|
| add_ops_compile_options | 部分使用 | 必须 |
| add_modules_sources | 使用 | 不使用 |
| target_sources | 隐式 | 显式列出 |
| common sources | 隐式链接 | 显式相对路径 |
| op_host_aclnnInner | 无 | 有 |
| opmaster_ct | 无 | 有 (NOT BUILD_OPEN_PROJECT) |
| install header | 无 | 有 |
| add_opapi_modules | 无 | 有 (NOT BUILD_OPS_RTY_KERNEL) |

### 5.2 v3 CMakeLists 必须包含的 target

```cmake
# 必须包含的 target_sources
target_sources(op_host_aclnnInner PRIVATE
    op_host/ai_infra_quant_batch_matmul_v3_def.cpp
)

target_sources(optiling PRIVATE
    op_host/ai_infra_quant_batch_matmul_v3_tiling.cpp
    op_host/ai_infra_quant_batch_matmul_v3_basic_tiling.cpp
    op_host/ai_infra_quant_batch_matmul_v3_tiling_base.cpp
    op_host/ai_infra_quant_batch_matmul_v3_tiling_cache.cpp
    op_host/platform_util.cpp
    ../common/op_host/op_tiling/debug_tiling.cpp
    ../../common/src/op_host/op_cache_tiling.cpp
    ../../common/src/op_host/runtime_kb_api.cpp
    ../../common/src/legacy_common_manager.cpp
)

target_sources(opsproto PRIVATE
    op_host/ai_infra_quant_batch_matmul_v3_infershape.cpp
)

target_sources(opapi PRIVATE
    op_api/aclnn_ai_infra_quant_matmul_v3.cpp
    op_api/aclnn_ai_infra_quant_matmul_v4.cpp
    op_api/ai_infra_quant_matmul_v3.cpp
    op_api/quant_matmul_checker.cpp
    ../common/op_host/op_api/matmul_util.cpp
)
```

### 5.3 v4 CMakeLists 特殊点

- V5 aclnn 由 v4 自己负责编译和安装
- 不跨目录引用（v3 不引 v5）
- install 只安装本目录的 aclnn_ai_infra_quant_matmul_v5.h

## 9. 总结

### 9.1 核心变化原则

1. **命名统一**: 加 AiInfra 前缀，全改名
2. **结构简化**: 删除非 A2A3 相关代码
3. **显式声明**: CMakeLists target_sources 显式列出
4. **依赖清晰**: common 代码相对路径引用

### 9.2 关键风险

| 风险 | 缓解 |
|------|------|
| arch20 4 处挂钩漏删 | 逐行检查 tiling.cpp |
| KB 改名不一致 | 文件名 + 内容 sed |
| CMake 依赖缺失 | 对照 ai_infra_matmul |
| 命名漏改 | 全 grep 无残留 |

### 9.3 参考模板

**ai_infra_matmul 完整路径**:
```
omni-ops/inference/ascendc/src/ops-nn/matmul/ai_infra_matmul/
```

这是 QBMM 迁移的权威参考，所有设计决策都应与之对齐。
